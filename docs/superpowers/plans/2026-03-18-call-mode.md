# Call Mode Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement Call mode — right-swipe a mutual's card to adopt their theme and status color; both cards pulse; either user left-swipes to exit.

**Architecture:** New utilities (`hexToRgb`, `setCallState`, `clearCallState`) underpin the feature. `following.js` owns all call mode state (`callModeCalleeId`, `callModeSnapshot`) and exports `enterCallMode`, `exitCallMode`, `reEnterCallMode` for use by the swipe gesture and app.js restart path. `app.js` adds restart detection via the first event of the existing `watchStatus` subscription.

**Tech Stack:** Vanilla JS ES modules, Firebase RTDB, Jest + jsdom.

```js
export function hexToRgb(hex) {
  const m = /^#?([0-9a-f]{2})([0-9a-f]{2})([0-9a-f]{2})$/i.exec(hex);
  if (!m) return '0, 0, 0';

}
```

```js
export async function setCallState(callerId, calleeId) {
  await update(ref(db, `users/${callerId}`), {
    callState: { calleeId, since: Date.now() },
  });
}

export async function clearCallState(callerId) {
  await update(ref(db, `users/${callerId}`), { callState: null });

// One-time read of a user's full document. Returns data object or null.
```

**`enterCallMode(calleeEntry, myUserId)`:**
1. If not already in call mode, snapshot own `--my-status` CSS var.
2. Set `callModeCalleeId = calleeEntry.userId`.
3. Call `setCallState(myUserId, calleeEntry.userId)` (fire-and-forget).
4. Get `calleeData = lastUserData.get(calleeEntry.userId)`.
5. If `calleeData.paletteKey`, call `applyThemeVars(getPaletteByKey(calleeData.paletteKey).theme)`.
6. Set `--my-status` and `--my-glow` from `calleeData.statusColor || '#22c55e'` using `hexToRgb`.
7. Call `setStatusColor(myUserId, color)` (fire-and-forget).
8. On the callee `<li>`: clear knock inline styles (`boxShadow`, `transition`), set `--call-color-rgb`, add `.call-mode`.
9. Call `renderList()`.

**`exitCallMode(myUserId)`:**
1. Capture `prevCalleeId = callModeCalleeId`.
2. Determine `revertColor`: use `callModeSnapshot` if available; else use active palette's primary color from `getPaletteState()`.
3. Call `clearCallState(myUserId)` (fire-and-forget).
4. Reset `callModeCalleeId = null` and `callModeSnapshot = null`.
5. Revert theme: `applyThemeVars(ownPalette.theme)` if palette active, else `resetThemeVars()`.
6. Set `--my-status` and `--my-glow` from `revertColor` using `hexToRgb`.
7. Call `setStatusColor(myUserId, revertColor)` (fire-and-forget).
8. Remove `.call-mode` and `--call-color-rgb` from old callee's card.
9. Call `renderList()`.

Replace the existing `sortFollowees` nested function inside `renderList` with:

```js
function sortFollowees(entries) {
  return [...entries].sort((a, b) => {
    if (callModeCalleeId) {
      if (a.userId === callModeCalleeId) return -1;
      if (b.userId === callModeCalleeId) return 1;
    }
    const aData = lastUserData.get(a.userId);
    const bData = lastUserData.get(b.userId);
    const aAvail = aData ? aData.status === 'available' && !isExpired(aData.availableUntil) : false;
    const bAvail = bData ? bData.status === 'available' && !isExpired(bData.availableUntil) : false;
    if (aAvail !== bAvail) return bAvail ? 1 : -1;
    const aName = a.label || a.code;
    const bName = b.label || b.code;
    return aName.localeCompare(bName);
  });
}
```

```js
    let swipeStartX = 0, swipeStartY = 0, swipeCardWidth = 0, swipeActive = false;

      swipeStartX = e.clientX;

            clearCallState(entry.userId).catch(() => {});

      }
    });
```
